# 13F 持仓变化分析功能更新

## 更新日期
2026-01-25

## 更新内容

### 核心改进：基于持股数的变化追踪

之前的版本基于**市值（美元）**来比较持仓变化，现已改为基于**持股数量**来进行对比分析。这样可以更准确地反映投资者的实际操作行为。

### 表格显示调整

#### 之前的列：
- \# (序号)
- 发行人
- CUSIP
- 当前市值
- 变化（箭头）
- 变化金额
- 股数

#### 现在的列：
- \# (序号)
- 发行人
- **上期持股** (上一季度的持股数量)
- **本期持股** (当前季度的持股数量)
- 变化（箭头/标记）
- **股数变化** (绝对数量变化)
- **变化%** (百分比变化)

### 变化标记说明

| 标记 | 含义 | 背景高亮 | 判断依据 |
|------|------|----------|----------|
| 🆕 | 新建仓位 | 深绿色 | 上期持股 = 0，本期持股 > 0 |
| ↑ | 增持 | 深绿色 | 股数变化 > 0 |
| ↓ | 减持 | 暗红色 | 股数变化 < 0 |
| — | 持平 | 无 | 股数变化 = 0 |

### 统计摘要

表格底部的统计摘要现在显示：
- 🆕 新建仓位的数量 及 总新增股数
- ↑ 增持的数量 及 总增持股数
- ↓ 减持的数量 及 总减持股数

示例：
```
🆕 新建: 3  ↑ 增持: 1  (+106,841,787 股)  |  ↓ 减持: 6  (-358,240,503 股)
```

## 使用方法

### 交互式查看器
```bash
python view_13f_holdings.py
```

### 快速演示（推荐）
```bash
python demo_13f_changes.py
```

这将自动展示 Berkshire Hathaway (Ticker: B) 的最新两个季度的持仓变化。

## 示例输出解读

以 Berkshire Hathaway 2024-Q3 → 2024-Q4 为例：

```
│ 1  │ BANK AMER CORP     │ 1,032,852,007 │ 797,683,307 │ ↓ │ -235,168,699 │ -22.8% │
│ 4  │ APPLE INC          │   400,000,000 │ 300,000,000 │ ↓ │ -100,000,000 │ -25.0% │
│ 8  │ SIRIUS XM HOLDINGS │             0 │ 105,155,029 │🆕│ +105,155,029 │   New  │
```

**解读：**
- **Bank of America**: 从10.33亿股减持至7.98亿股，减少了2.35亿股（-22.8%）
- **Apple**: 从4亿股减持至3亿股，减少了1亿股（-25.0%）
- **Sirius XM**: 新建仓位，买入1.05亿股

## 技术实现

修改的主要文件：
- `view_13f_holdings.py`: 核心显示逻辑
  - `_display_multi_period_holdings()`: 多期对比显示方法
  - 变化类型判断逻辑从市值改为股数
  - 表格列从市值相关改为股数相关

## 优势

1. **更准确的投资行为追踪**: 股数变化直接反映买卖操作，不受股价波动影响
2. **清晰的数据对比**: 上期/本期持股数并排显示，一目了然
3. **百分比变化**: 直观显示增持/减持的幅度
4. **视觉高亮**: 绿色高亮增持，红色高亮减持，快速识别投资决策

## 兼容性

- 向后兼容，单期数据查看功能保持不变
- 仅在多期对比时启用新的变化分析功能
