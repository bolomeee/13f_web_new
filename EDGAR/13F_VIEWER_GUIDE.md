# 13F 持仓数据查看器使用指南

## 概述

本工具提供了两种方式查看 13F-HR 持仓报告数据：

1. **交互式查看器** (`view_13f_holdings.py`) - 功能完整的交互式界面
2. **快速查看工具** (`quick_view_13f.py`) - 命令行快捷查看

## 1. 交互式查看器

### 启动方式

```bash
python view_13f_holdings.py
```

### 功能特点

- 🎨 精美的 Rich 表格展示
- 📊 自动加载所有 13F 报告
- 🔍 交互式选择 Ticker 和日期
- 📈 Top 持仓排名
- 💰 详细持仓列表
- 📊 多期数据对比

### 使用流程

1. **启动程序** - 自动扫描 `JSON_Reports/` 目录
2. **选择 Ticker** - 从可用列表中选择要查看的公司
3. **选择日期范围** - 可选：
   - `latest` - 仅最新一期
   - `all` - 所有时期
   - `range` - 指定范围
   - `single` - 单个日期
4. **查看数据** - 自动显示：
   - 持仓汇总信息
   - Top 10 持仓排名
5. **可选操作**：
   - 查看详细持仓列表（可指定显示数量）
   - 查看多期对比（仅当选择多期时）

## 2. 快速查看工具

### 基本用法

```bash
python quick_view_13f.py --ticker <TICKER> [选项]
```

### 参数说明

| 参数 | 简写 | 说明 | 默认值 |
|------|------|------|--------|
| `--ticker` | `-t` | 要查看的 Ticker（必需） | - |
| `--date` | `-d` | 日期选项：latest/all/具体日期 | latest |
| `--top` | - | 显示 Top N 持仓（0=不显示） | 10 |
| `--detail` | - | 显示详细持仓数量（0=不显示） | 0 |
| `--compare` | - | 显示多期对比 | False |

### 使用示例

#### 查看最新一期的 Top 10 持仓

```bash
python quick_view_13f.py --ticker B --date latest --top 10
```

#### 查看特定日期的详细持仓（前 50 个）

```bash
python quick_view_13f.py --ticker B --date 2024-11-14 --detail 50
```

#### 查看所有时期并进行对比

```bash
python quick_view_13f.py --ticker B --date all --top 5 --compare
```

#### 完整示例：查看所有数据

```bash
python quick_view_13f.py --ticker B --date all --top 10 --detail 30 --compare
```

## 3. 数据说明

### 持仓汇总信息

- **总持仓数量** - 不同 CUSIP 的总数
- **总市值** - 所有持仓的总市值（美元）
- **平均持仓价值** - 平均每个持仓的市值

### Top 持仓表格

显示按市值排名的前 N 大持仓：

- **排名** - 按市值从高到低排序
- **发行人** - 公司名称
- **CUSIP** - 9位唯一标识符
- **市值** - 持仓价值（美元）
- **占比** - 占总投资组合的百分比

### 详细持仓列表

显示所有持仓的详细信息（自动合并相同 CUSIP）：

- **发行人** - 公司名称
- **CUSIP** - 证券标识符
- **市值** - 总持仓价值
- **股数** - 总持股数量
- **估算股价** - 基于市值/股数计算
- **记录数** - 该 CUSIP 在原始数据中的条目数

### 多期对比

比较不同时期的投资组合变化：

- **持仓数量变化** - 持仓种类的增减
- **总市值变化** - 投资组合规模的变化
- **变化百分比** - 相对于首期的变化率

## 4. 技巧和注意事项

### 数据合并

由于同一个 CUSIP 可能在 13F 原始数据中有多条记录（不同账户或管理人），详细持仓视图会自动将同一 CUSIP 的记录合并，显示总计数据。

### 估算股价

`price_per_share_estimated` 是根据市值除以股数计算的估算值，可能与实际市场价格略有差异。

### 多期对比的使用场景

- 追踪机构投资者的持仓变化趋势
- 识别增持或减持的股票
- 分析投资组合的调整策略
- 监控总资产规模的变化

## 5. 故障排除

### 问题：找不到 Ticker

**解决方案**：
1. 确认 `JSON_Reports/` 目录中有对应的 JSON 文件
2. 检查文件名格式是否正确
3. 运行交互式查看器查看所有可用的 Ticker

### 问题：日期不存在

**解决方案**：
1. 使用 `--date all` 查看所有可用日期
2. 检查日期格式是否为 `YYYY-MM-DD`

### 问题：显示异常

**解决方案**：
1. 确保已安装 `rich` 库：`pip install rich`
2. 终端需要支持 UTF-8 和彩色输出
3. 调整终端窗口大小以适应表格宽度

## 6. 扩展功能

### 导出数据

可以通过重定向输出保存查看结果：

```bash
python quick_view_13f.py --ticker B --date all --compare > report.txt
```

### 批量查看

使用 shell 脚本批量查看多个 Ticker：

```bash
for ticker in B JPM GS; do
    echo "=== $ticker ==="
    python quick_view_13f.py --ticker $ticker --top 5
done
```

## 8. 性能建议

- 查看单个日期的数据响应最快
- 查看所有日期并对比时，建议限制 Top 持仓数量
- 详细持仓列表建议限制在 50-100 条以内
- 大量数据时可以使用快速查看工具而非交互式界面
